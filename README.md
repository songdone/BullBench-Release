# BullBench 牛犇｜反馈与版本信息

BullBench 牛犇是一款面向 NAS 的性能测试应用。本仓库用于收集问题反馈和功能建议；应用源码不在此仓库公开。

- [提交问题或建议](https://github.com/songdone/BullBench-Release/issues)
- [查看版本发布](https://github.com/songdone/BullBench-Release/releases)

项目尚在开发和测试中，安装渠道、版本状态以实际发布说明为准。

## 提交反馈

请说明应用版本、fnOS 版本、设备架构、发生问题的步骤以及预期结果；如有帮助，可附上已检查过内容的截图。请勿在公开反馈中发布密码、访问令牌、设备序列号、内网地址或私人文件。
