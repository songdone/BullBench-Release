# BullBench 牛犇｜NAS 性能测试与排行榜

**牛不牛，跑分见。**

BullBench 牛犇是为飞牛 fnOS 打造的 NAS 性能测试应用：真实负载跑分（CPU / 内存 / 存储）、统一综合评分、历史成绩对比、跨设备公开榜与竞技场。测试本机离线完成，云端上传与公开完全由你逐项授权。

- [下载与版本发布（源码仓 Release）](https://github.com/songdone/bullbench/releases)
- [提交问题或建议](https://github.com/songdone/BullBench-Release/issues)

## 当前版本：0.9.2（首发候选）

| 能力 | 说明 |
|---|---|
| 综合评分 | `score-v3-unified`：同一场次 CPU / 内存 / 存储（1024 MiB 工作集、直连 I/O）实测得出综合总分；128/256/512 MiB 为扩展测试，只展示原始成绩、不参与统一榜 |
| 公开榜 | 授权公开的有效成绩自动上榜；同筛选范围排名、成绩分布曲线、冠军卡、硬件型号展示 |
| 历史对比 | 每场次较上次 / 历史最佳差值、双场次对比、历史综合分趋势图 |
| 硬件型号识别 | 读取 DMI / 设备树 / PCI 型号字段，轻量匹配品牌 NAS / 迷你主机 / 开发板；虚拟机优先显示虚拟平台；未识别不影响任何功能 |
| 竞技场与特色榜 | 真实硬件分数对比、性能画像、基于真实 CPU 单核成绩的趣味榜 |
| 影音测试 | FFmpeg 实时转码帧率与 SSIM 质量门槛（fnOS 自带影视服务提供 FFmpeg） |

## 安装（fnOS 1.2.0401 及以上）

1. 在 fnOS 应用中心搜索「牛犇」安装（推荐），或从 [Release 页](https://github.com/songdone/bullbench/releases) 下载对应架构的 FPK 手动导入：
   - `bullbench-0.9.2-x86.fpk`（x86-64）
   - `bullbench-0.9.2-arm.fpk`（ARM64）
2. 安装前可用 `SHA256SUMS-0.9.2.txt` 校验文件完整性。
3. 打开应用 → 开始测试 → 完成核心三项 → 得到综合分；是否上传、是否公开由你在设置页逐项决定，默认全部关闭。

## 升级与数据安全

- 覆盖升级保留本机全部测试记录与设置；卸载前请确认不再需要本机数据。
- 关闭「允许公开」会立即把你的成绩从公开榜移除；恢复公开只重新发布仍有效的成绩。
- 删除设备会级联删除云端全部相关记录。

## 隐私说明

- 云端开关默认关闭；只有你手动开启后才会上传成绩，且上传与公开是两个独立开关。
- 上传内容仅限：匿名设备编号、设备名、CPU 型号与核心数、内存容量、架构与虚拟化类型、测试指标。**不读取**硬盘序列号、MAC 地址、设备 UUID、用户文件、媒体库内容。
- 硬件型号识别只读取 DMI / 设备树 / PCI 的型号字段（如厂商与主板名），不采集任何序列号。
- 虚拟机成绩单独标注，不与原生设备混排。
- 公开成绩可匿名举报：只提交成绩编号、类型与理由，不发送本机身份。
- 完整用户协议与隐私政策在应用内「设置 → 用户协议与隐私政策」。
